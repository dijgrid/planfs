# Insights Timeline

The timeline turns task due dates, milestone delivery targets, and optional epic planning dates into a planning map. A milestone target date is the preferred delivery commitment for a release, sprint, launch, or checkpoint. An epic date is a lightweight planning horizon for its scope; it does not replace a milestone commitment.

Use grouping and density controls to reduce visual noise. Undated items stay visible so missing schedule metadata does not disappear from planning conversations.
