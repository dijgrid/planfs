# Structured Editor

The structured editor keeps frequent metadata changes fast while preserving the Markdown file as the source of truth. Use compact fields for status, priority, ownership, dates, tags, and relationships.

Common Markdown sections such as Acceptance Criteria, Questions, and task Findings are shown for review. Findings remain read-only in the structured editor so evidence, checklists, links, and code snippets stay authored in the canonical Markdown file. Use Open Markdown when you need to edit the full body, add new sections, or make prose-heavy changes.

Editors retain unsaved form drafts during repository refreshes. If the file changes on disk, PlanFS keeps your draft and offers Reload from disk, Open Markdown to compare it, or an explicit retry after you have reviewed the change.
